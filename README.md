## Projetos

### [Lepidox](https://github.com/AdrielGTeles/lepidox)
Extensão open source para Chrome e Edge que rotaciona dashboards em telas de parede, salas de crise e NOCs. Pré-carrega as páginas vizinhas, recupera abas fechadas, avisa quando uma tela cai na página de login e funciona em português e inglês, sem backend nem coleta de dados.

[Chrome Web Store](https://chromewebstore.google.com/detail/nbjokomgnlbodofhnpgdppahkjpglnjp) · [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/mmieebnhiodfadbajdnbdeapdhajilef) · JavaScript, Manifest V3
